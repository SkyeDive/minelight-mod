# Minelight

A Minecraft mod for JE 1.20.1 + Fabric for allowing players to possess each other via streaming input data and visuals.

This project is still in development, and as such no release builds are available yet. I've uploaded this project at its current state as a way to back up the files in case of an emergency, and as a way to document my progress and coding style to potential employers and those interested.

Minelight's name and concept were inspired by the incredible [Moonlight](https://github.com/moonlight-stream/moonlight-qt) project, go check it out and consider supporting the devs!

## Dependencies
* Fabric API (minimum version to be determined)
